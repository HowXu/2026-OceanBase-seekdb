## 需要覆盖的官方验收范围

1. DDL、表达式与依赖校验、配置和状态元数据、结果类型提示及校验（8 分）。
2. INSERT/UPDATE/DELETE、批量、主键变更、任务与结果失效的事务一致性、回滚与清理（10 分）。
3. 持久化调度、并发领取、中断恢复、定义版本和请求归属校验、分组原子发布、迟到结果保护（12 分）。
4. 有限自动重试、条件 RETRY、状态伪列、列级严格读取及 SELECT/UPDATE/DELETE 错误语义（10 分）。
5. 向量生成、HNSW/VSAG 索引、ANN、失效与重算、事务回滚下的数据和索引一致性（10 分）。

## 边界

- MySQL 模式，仅异步生成，不要求 AI 列链式依赖。
- 必须在数据库内核中实现，不能使用应用侧轮询脚本替代。
- 模型请求必须发生在业务事务提交后，回滚事务不能触发请求。
- 不能仅凭结果是否 NULL 判断任务完成。
- 同行同次变更的一组 AI 列达到终态后同事务发布，允许 READY 和 FAILED 混合。
- 严格读取按被引用 AI 列的完整性检查，不得被业务 WHERE 过滤绕过。
- 确定性 Mock 与官方测试、故障恢复专项、性能证据分别记录；不承诺未实际验证的通过结果或比赛分数。
